# Freeman ONE

Исходники веб-сайта и Telegram-бота. Оба канала используют общий Python backend и PostgreSQL.

Код `app/`, ресурсы сайта и файлы `requirements*.txt` зафиксированы из работающего контейнера `freemanone-bot-1` 18 ноября 2026 года. Контейнер `5b95816b19bf` запущен 17 ноября в 19:38 UTC, образ `sha256:f2ed651800126c04f3310e74042fbaf2c33109c1fdc62fbf1a70ab8e928c4b7f`. Снимок включает файлы, подключённые как bind mounts внутри приложения.

- `app/main.py` собирает FastAPI, Telegram и фоновые процессы.
- `app/bot/` содержит обработчики Telegram, `app/web/` — веб-маршруты и интерфейс.
- `app/services/` связывает оплаты, подписки, поддержку и интеграции.
- `app/database/` содержит модели, репозитории и миграции.

Для локальной настройки используйте `.env.example` с тестовыми значениями и [описание миграций](docs/DATABASE-MIGRATION-ORCHESTRATION.md).
